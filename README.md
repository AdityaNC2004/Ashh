# For Ashuu ♡

A responsive, static scrapbook site made for Ashuu. The selected 30 photos are included in `photos/`; the site runs without a build step and can be deployed directly to Vercel.

## Preview and deploy

Open `index.html` in a browser to preview. To publish, import this folder as a project in Vercel and choose **Other** with no build command and `.` as the output directory. You can also drag the project folder into Vercel's deployment flow.

All images are local project files, so they will be included in the deployment. To swap a picture, replace its matching `photos/NN.jpg` file. The browser gallery shows 30 photos.
