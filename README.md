# Aditi ♡

A responsive, static scrapbook site made for Aditi. All 69 photos in `photos/` appear in the memory wall and can be opened in the photo viewer. The site runs without a build step and can be deployed directly to Vercel.

## Preview and deploy

Open `index.html` in a browser to preview. To publish, import this folder as a project in Vercel and choose **Other** with no build command and `.` as the output directory. You can also drag the project folder into Vercel's deployment flow.

All images are local project files and will be included in the deployment. Add or remove supported image files in `photos/` and update the `photoFiles` list in `script.js` to change the gallery.
